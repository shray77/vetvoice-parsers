# VetVoice — UX/UI фишки и roadmap

Идеи для развития Flutter-приложения vetvoice (репозиторий `shray77/vetvoice`
на GitLab). Сгруппированы по приоритету. Каждая идея с описанием, пользой
и прикидкой сложности реализации.

---

## 🔴 Приоритет 1 — critical UX

### 1.1. Vaccine-specific экран (зависит от vaccine_extractor.py)

**Проблема:** Сейчас вакцины помечены как `form_type=vaccine`, но UI
прогоняет их через обычный калькулятор (dose_per_kg × weight). Для вакцин
это бессмысленно — там разовая доза.

**Решение:** Отдельный экран/карточка для вакцин.

```
┌─────────────────────────────────────┐
│  💉 ГАМБОХЕТЧ                       │
│  Вакцина против инфекционного       │
│  бронхита кур живая                 │
├─────────────────────────────────────┤
│  Разовая доза:  4 мл (1 доза)       │
│  Путь:          спрей-метод         │
│  Схема:         ревакцинация через  │
│                 21 день             │
├─────────────────────────────────────┤
│  📦 Фасовка:                        │
│  ○ 2000 доз (8 мл)                  │
│  ○ 4000 доз (16 мл)                 │
│  ● 5000 доз (20 мл)                 │
├─────────────────────────────────────┤
│  Для: Птица                         │
│  Срок годности: 18 мес при 2-8°C    │
│  Хранение: в холодильнике           │
└─────────────────────────────────────┘
```

**Что нужно в коде:**
- Новая модель `VaccineSpecific` в `lib/models/calc_drug.dart`
- В `result_card.dart` — проверка `if (drug.formType == 'vaccine')` → другая карточка
- В `home_screen.dart` — не показывать поле ввода веса для вакцин

**Сложность:** 🟡 средняя (1-2 дня)
**Зависимости:** `vaccine_extractor.py` (готов)

---

### 1.2. Цветовое кодирование по категории

**Проблема:** Сейчас все препараты в списке выглядят одинаково.
Тяжело найти антибиотик среди витаминов.

**Решение:** Цветные полоски слева от названия:

```
🔴 Антибактериальные    — красный
🔵 Вакцины              — синий
🟢 Витамины/Минералы    — зелёный
🟡 НПВС/Анальгетики     — жёлтый
🟣 Противопаразитарные  — фиолетовый
⚫ Прочие              — серый
```

**Сложность:** 🟢 низкая (2-3 часа)
**Файлы:** `lib/widgets/drug_dropdown.dart`, `lib/utils/app_theme.dart`

---

### 1.3. Избранное препаратов

**Проблема:** Ветврач каждый раз ищет 5-10 своих любимых препаратов
(например, маропитант, мелоксикам, амоксициллин).

**Решение:** Кнопка ⭐ в карточке препарата, вкладка «Избранное» на главном экране.

**Сложность:** 🟢 низкая (4 часа)
**Файлы:** `lib/providers/vet_provider.dart` (SharedPreferences для сохранения),
новый экран `lib/screens/favorites_screen.dart`
**В README уже есть в TODO: «Избранное препаратов»**

---

### 1.4. История расчётов

**Проблема:** После расчёта дозы ветврач закрывает приложение — и всё
пропадает. Хочется посмотреть «что я считал 10 минут назад».

**Решение:** Лог последних 50 расчётов, отдельный экран с историей.

```
┌─────────────────────────────────────┐
│  🕒 История расчётов                │
├─────────────────────────────────────┤
│  15:42  Мариния®  12 кг собака     │
│         → 1.2 мл внутримышечно     │
│  15:38  Амоксиклав  20 кг собака   │
│         → 4 мл перорально           │
│  15:21  Флорфорте  450 кг КРС      │
│         → 45 мл подкожно            │
└─────────────────────────────────────┘
```

**Сложность:** 🟢 низкая (4 часа)
**Файлы:** новый экран `lib/screens/history_screen.dart`, в `vet_provider.dart` добавить
метод `addCalculationToHistory()`
**В README уже есть в TODO: «История расчётов»**

## 🟡 Приоритет 2 — improvement

### 2.1. Протоколы лечения — закрепление препаратов

**Проблема:** В `treatment_protocols.json` есть 100+ протоколов
(например «Лечение пиодермии у собак»), но они не связаны с препаратами
из `drugs_calc.json`.

**Решение:** Кнопка «📜 Применить протокол» на главном экране → выбор протокола →
автозаполнение списка препаратов + их доз по весу.

```
┌─────────────────────────────────────┐
│  📜 Протокол: Пиодермия у собак     │
├─────────────────────────────────────┤
│  1. Амоксиклав    → 250 мг          │
│     перорально, 7 дней              │
│  2. Мариния®      → 1.2 мл          │
│     подкожно, 5 дней                │
│  3. Иммунофан®    → 1 мл            │
│     подкожно, 3 дня                 │
├─────────────────────────────────────┤
│  [📋 Сохранить как PDF] [📤 Поделиться] │
└─────────────────────────────────────┘
```

**Сложность:** 🟡 средняя (1 день)
**Файлы:** новый экран `lib/screens/protocol_screen.dart`,
`lib/providers/vet_provider.dart` добавить метод `applyProtocol()`

---

### 2.2. Поиск по симптомам/показаниям

**Проблема:** Ветврач знает симптом («рвота у собаки»), но не знает какой препарат.

**Решение:** Поле «Что у пациента?» с автодополнением по `indications` из drugs_calc.

```
┌─────────────────────────────────────┐
│  🔍 Что у пациента?                 │
│  [рвота у собаки              ]     │
├─────────────────────────────────────┤
│  Найдено 5 препаратов:              │
│  • Мариния® (маропитант)           │
│    Противорвотное, 1 мг/кг         │
│  • Ондансетрон                     │
│    Противорвотное, 0.5 мг/кг       │
│  • Метоклопрамид                   │
│    Прокинетик, 0.5 мг/кг           │
└─────────────────────────────────────┘
```

**Сложность:** 🟡 средняя (1 день, нужно нормализовать indications и построить
обратный индекс)
**Файлы:** новый экран `lib/screens/symptom_search_screen.dart`,
в `vet_provider.dart` добавить метод `searchByIndications()`

### 2.3. Interactions checker — интерактивный

**Проблема:** В `drug_interactions.json` есть данные, но они только показываются
как предупреждение. Хочется: выбрать 2-3 препарата и сразу увидеть их совместимость.

**Решение:** Отдельный экран «Проверка совместимости»:

```
┌─────────────────────────────────────┐
│  🧪 Проверка совместимости          │
├─────────────────────────────────────┤
│  [+ Добавить препарат]              │
│                                     │
│  1. Мариния® (маропитант)           │
│  2. Метоклопрамид                   │
├─────────────────────────────────────┤
│  ⚠️  Внимание:                      │
│  Мариния + Метоклопрамид —          │
│  антагонисты по серотониновым       │
│  рецепторам. Не рекомендуется       │
│  одновременное применение.          │
└─────────────────────────────────────┘
```

**Сложность:** 🟡 средняя (1 день)
**Файлы:** расширить `lib/widgets/compatibility_checker.dart` или новый экран

### 2.4. Тёмная тема

**Проблема:** Ночью/в клинике яркий экран слепит.

**Решение:** ThemeMode.system + переключатель в настройках.

**Файлы:** `lib/utils/app_theme.dart` (добавить darkTheme), `lib/screens/settings_screen.dart`

## 🟢 Приоритет 3 — nice-to-have

### 3.1. Экспорт PDF/CSV с историей расчётов

**Проблема:** Ветврач хочет распечатать или отправить коллеге историю
расчётов за день.

**Решение:** Кнопка «📤 Поделиться» в history_screen → генерация PDF
(через `pdf` package) или CSV.

**Сложность:** 🟡 средняя (1 день, изучить `pdf` package)

---

### 3.2. Калькулятор скорости инфузии

**Проблема:** В `fluid_therapy.json` есть формулы, но нет расчёта
капель/мин для шприцевого насоса.

**Решение:** Отдельный экран «Капельница»:

```
┌─────────────────────────────────────┐
│  💧 Калькулятор инфузии             │
├─────────────────────────────────────┤
│  Раствор:     NaCl 0.9%             │
│  Препарат:    Дофамин 4%            │
│  Доза:        5 мкг/кг/мин          │
│  Вес:         20 кг                 │
├─────────────────────────────────────┤
│  Скорость:    1.5 мл/ч              │
│  Капель:      30 кап/мин            │
│  Длительность: 10 ч (флакон 50 мл)  │
└─────────────────────────────────────┘
```

**Сложность:** 🟡 средняя (1 день)

---

### 3.3. OCR этикетки препарата (фото → текст)

**Проблема:** У ветврача в руках флакон, не понятно что это.

**Решение:** Кнопка 📷 → Google ML Kit / Tesseract OCR → распознавание
названия → поиск в базе.

**Сложность:** 🔴 высокая (2-3 дня, нужна интеграция с OCR-библиотекой)
**В README уже есть в TODO: «OCR этикетки»**

---

### 3.4. Голосовой ввод веса и дозы

**Проблема:** Сейчас голосом можно искать препарат, но вес всё равно
вводить руками.

**Решение:** Распознавать фразы «собака двадцать килограмм» → 20 кг.

**Сложность:** 🟡 средняя (нужно расширить speech_service для парсинга чисел)

---

### 3.5. Multi-language (English + 中文)

**Проблема:** Для иностранных студентов-ветеринаров в РФ.

**Сложность:** 🟡 средняя (1-2 дня, intl package + .arb файлы)

---

### 3.6. Push-уведомления об обновлениях базы

**Проблема:** База drugs_calc обновляется раз в месяц, но пользователь
не знает.

**Решение:** При запуске — чекать `last_updated` и показывать banner
«Доступна новая база от YYYY-MM-DD, обновить?»

**Сложность:** 🟢 низкая (2 часа)

---

### 3.7. Каренція-калькулятор (для продуктовой группы)

**Проблема:** После применения препарата корова даёт молоко. Когда
можно пить? Зависит от withdrawal_days.

**Решение:** Калькулятор «Каренция»: вводишь препарат + дату введения
→ получаешь дату, когда молоко/мясо безопасно.

```
┌─────────────────────────────────────┐
│  🐄 Калькулятор каренции            │
├─────────────────────────────────────┤
│  Препарат:    Амоксициллин 15%      │
│  Животное:    КРС (молочная корова) │
│  Дата:        15.08.2026            │
├─────────────────────────────────────┤
│  🥛 Молоко безопасно с: 17.08.2026  │
│  (48 часов задержки)                │
│  🥩 Мясо безопасно с:   12.09.2026  │
│  (28 дней задержки)                 │
└─────────────────────────────────────┘
```

**Сложность:** 🟡 средняя (нужно расширить withdrawal_by_product.json
и написать калькулятор)
